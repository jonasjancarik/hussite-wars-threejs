# Painted ground

`painted-ground.png` is copied unchanged from Jonas's `procedural-worlds/web/public/assets/textures/T_ConceptBGroundCalm.png`, reused with his explicit permission for this battlefield study. It is a painted olive/ochre ground tile, repeated every 32 scene units. Broad terrain vertex colors add larger-scale variation.

This is illustrative art material. It is not a texture derived from the Sudoměř elevation source.

`earth-grain.png` is copied unchanged from `procedural-worlds/web/environment-packs/coastal-courtyard/textures/coastal-road.png` under the same permission. The road material tints this neutral grain toward dry earth; vertex alpha feathers the ribbon edges into the ground.

`sudomer-pond-mud.png` is a generated repeating diffuse texture for the drained Škaredý basin, produced with the built-in image-generation tool on 2026-09-20. The exact prompt is retained in `assets/terrain/sudomer/mud-prompt.txt`. It represents illustrative damp silt, not a sampled historical surface.

`sudomer-meadow.png` is a new muted early-spring meadow diffuse tile generated with the built-in image tool on 2026-09-20. Its exact prompt is in `assets/terrain/sudomer/meadow-prompt.txt`. The Sudoměř renderer blends its appearance with a separate reused earth-grain layer for fields, tracks and damp banks.
